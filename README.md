# 🛒 TechStore Smart Support

**Checkpoint 03 — Smart Assistant | FIAP · Prompt and Artificial Intelligence**
**Grupo: WeAreTheSix**

Assistente de suporte ao cliente da TechStore feito em Python. Ele recebe mensagens de clientes, classifica o tipo (reclamação, dúvida, elogio ou sugestão), processa de forma diferente dependendo do tipo, e gera uma resposta. Tudo com validação de JSON via Pydantic e proteção contra ataques de prompt injection.

## 🧠 Domínio

**E-Commerce — TechStore Smart Support**

Assistente que classifica e responde solicitações de clientes de uma loja de eletrônicos: reclamações, dúvidas, elogios e sugestões.

## ⚙️ Stack

- **Python** 3.10+
- **LLM**: Ollama local com modelo `llama3`
- **Validação**: Pydantic v2
- **Análise**: pandas + matplotlib
- **Tokens**: tiktoken
